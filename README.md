# Evelyn — Portfolio

Desktop-first design preview. Open index.html directly, or run `python -m http.server 4173 --bind 127.0.0.1` from this directory and visit http://127.0.0.1:4173.

## Design
One responsive navigation bar, whole-document scrolling, animated homepage artwork that expands on scroll, category folder tabs and in-page project sections, expandable Journey milestones, filterable Achievements cards, and a two-column About layout. Reduced-motion preferences disable decorative animation. Contact links stay visibly unavailable until supplied.

Content remains a draft. Existing source records are preserved in content.js; achievements and biography use design placeholders pending the content phase. No new outcomes or credentials have been added.

## Files
- index.html: document and single header
- styles.css: desktop and responsive styles
- app.js: navigation, filtering, scrolling and interactions
- content.js: existing source records
- assets/: existing images
- backups/: previous files saved before this redesign
