# Evelyn — Portfolio

A buildless, responsive HTML/CSS/JavaScript portfolio with five application-style views. Open `index.html` in a browser, or serve this directory using `python -m http.server 4173 --bind 127.0.0.1` and visit `http://127.0.0.1:4173`.

## Design and navigation

- Warm white canvas, charcoal/navy typography and muted green accents.
- Project folders across the top bring the selected project forward.
- Left explorer groups project files; additional content navigation switches between Overview, Approach & process, Evidence & output, and Reflection.
- Journey filters education, experience and major projects; milestone links open their canonical detail views.
- Achievements are grouped into Sports, Events & leadership, and Hackathons & pitching.
- About includes education, capabilities and space for professional contact links. No resume download.
- Hash routes work on static hosts and local files, including refresh and browser Back/Forward.
- On mobile, folder tabs scroll horizontally and the explorer opens with the Explore button.
